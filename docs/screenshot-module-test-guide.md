# Windows 截图模块测试指南

## 1. 目的与适用范围

本文用于验收 QuickClipboard Windows 截图模块。测试对象应为同一次 CI 或发布流程生成的标准便携程序或 NSIS 安装包；截图功能统一使用项目内置的 Windows.Graphics.Capture 实现。

覆盖范围：多 DPI、多显示器负坐标、4K、普通截图、复制、保存、贴图、AI 识别、入口、快捷键冲突、取消、显示器移除和历史去重。

不在当前范围：跨显示器选区、滚动截图、录屏、标注、窗口或控件识别、本地 OCR 回退。

## 2. 测试前准备

1. 使用同一次 CI 的便携版或安装包，不要混用旧版程序。
2. 首次启动后，在设置确认“启用截屏功能”打开，并记录截图快捷键；默认值为 Ctrl+Shift+A。
3. 准备含中文、英文、数字、小字号文字与高对比度区域的测试窗口，以及可验证粘贴结果的文本编辑器。
4. AI 场景需要有效 API Key、HTTPS 服务地址和明确支持视觉输入的模型。测试账户只应产生少量可控请求。
5. 每个场景记录：构建 run ID、Windows 版本、显卡驱动、显示器排列和缩放、入口、选区大小、实际结果、错误信息及是否写入剪贴板或历史。不得记录 API Key、认证头、完整 data URL 或选区原图。

## 3. 基础入口与取消

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| B01 | 从标题栏菜单启动普通截图 | 主窗口隐藏后出现全屏透明截图层，可拖出选区。 |
| B02 | 从托盘“截图”启动 | 与 B01 使用同一截图层，且不残留重复窗口。 |
| B03 | 使用全局快捷键启动 | 在普通前台应用中可启动；冲突状态下不执行错误动作。 |
| B04 | 未选区时按 Escape | 截图层关闭，主窗口恢复；不写剪贴板、不写历史。 |
| B05 | 已选区但未执行动作时按 Escape | 截图会话取消；不写剪贴板、不写历史、不遗留临时文件。 |
| B06 | 处理中尽快按 Escape | 迟到结果不得覆盖剪贴板或新建历史；截图层最终关闭。 |

## 4. 显示器、DPI 与坐标

每个缩放比例至少执行一次普通截图、一次复制和一次取消。

| 编号 | 环境和操作 | 通过标准 |
| --- | --- | --- |
| D01 | 单屏 100%，截取窗口边缘和右下角附近 | 选区边界无偏移，输出图片覆盖实际拖拽范围。 |
| D02 | 单屏 125%，重复 D01 | 逻辑坐标到物理像素换算正确，无明显缩放或裁切偏差。 |
| D03 | 单屏 150%，重复 D01 | 同 D02，工具栏仍在可见范围内。 |
| D04 | 副屏原点为负 X 或负 Y，在副屏启动并截取四角 | 截图层定位正确，不跳到主屏；复制结果与副屏选区一致。 |
| D05 | 4K 屏，截取接近全屏和小选区 | 首帧在合理时间内出现；无黑屏、空图或内存异常。 |
| D06 | 截图层打开后拔出当前显示器或切换投影模式 | 安全取消或显示可理解错误；不得崩溃、卡住或写到错误屏幕。 |

## 5. 四种动作与历史

每项动作前先画出明确选区。完成后打开主窗口检查历史，必要时用文本编辑器验证系统剪贴板。

| 编号 | 动作和操作 | 通过标准 |
| --- | --- | --- |
| A01 | 点击“复制”或按 Enter | 系统剪贴板可粘贴正确图片；历史只新增或刷新一条对应图片记录。 |
| A02 | 点击“保存”或按 Ctrl+S，选择新路径 | 保存文件为可打开 PNG；取消对话框不报错、不写历史。 |
| A03 | 点击“贴图”或按 Ctrl+P | 新贴图窗口显示正确图片；关闭后不残留截图窗口。 |
| A04 | 连续两次复制完全相同选区 | 内容地址相同的截图不会由监听器产生重复历史。 |
| A05 | 先取消一次，再重新截图复制 | 新会话正常完成，旧会话的迟到结果不影响新会话。 |

## 6. AI 视觉识别

### 6.1 配置测试

1. 在“截屏设置”检查“视觉配置状态”。
2. 未配置时，点击“配置 AI”应跳到 AI 配置区。
3. 配置有效时，点击“测试 AI 配置”。

通过标准：配置测试发送内置 1×1 测试图，不读取或发送用户截图；成功时显示成功提示。该测试不等同于真实选区识别。

### 6.2 首次真实识别与成功路径

| 编号 | 前置条件和操作 | 通过标准 |
| --- | --- | --- |
| I01 | AI 开关打开且视觉配置有效，选取文字图片并点击“AI 识别” | 首次出现云端发送说明；确认后才发送选区图片。 |
| I02 | 完成 I01 确认后再次识别 | 不重复弹确认框；识别文本写入剪贴板并新增一条文本历史。 |
| I03 | 关闭 AI 动作开关后选区 | AI 按钮不可用或不显示；复制、保存、贴图仍可用。 |
| I04 | 配置无效后选区 | AI 动作不可用且可进入配置页；其他动作不受影响。 |

### 6.3 错误分类

每个失败场景后，都要确认同一份本地截图仍可继续复制、保存或贴图。

| 编号 | 触发方式 | 通过标准 |
| --- | --- | --- |
| I05 | 使用错误 API Key | 提示认证失败；不泄露 Key、认证头或原始响应体。 |
| I06 | 使用会返回 429 的服务或账户 | 提示限流；不进行无限重试。 |
| I07 | 使用文本模型而非视觉模型 | 发请求前提示模型不支持视觉，或配置状态无效。 |
| I08 | 使用不可达 HTTPS 地址 | 提示网络失败或超时；不误判为认证失败。 |
| I09 | 服务返回无法解析的内容 | 提示响应格式错误；不展示原始响应或敏感数据。 |
| I10 | 发起识别后立即按 Escape | 迟到结果不得写入剪贴板或历史。 |

## 7. 快捷键冲突与恢复

1. 把截图快捷键设为其他全局快捷键已使用的组合。
2. 保存设置并检查快捷键错误状态。
3. 恢复为可用组合后再次保存。
4. 在主窗口、普通应用和贴图窗口场景分别触发一次。

通过标准：冲突组合有明确错误状态；失败注册不会留下幽灵快捷键；恢复后新快捷键可用，旧快捷键不再触发。

## 8. 结束检查

1. QuickClipboard 能正常退出和重新启动。
2. 不存在遗留截图透明层、贴图窗口或异常后台 CPU 占用。
3. 截图历史没有由同一次复制产生的重复记录。
4. 保存目录、贴图目录及临时目录没有异常膨胀。
5. 错误日志与通知中不包含 AI 凭据或用户选区原始数据。

## 9. 缺陷报告最小信息

报告缺陷时请附：场景编号、QuickClipboard 版本和构建 run ID、Windows 版本、显卡和驱动、显示器分辨率/排列/缩放、实际与预期结果、可脱敏的错误信息或录屏、稳定复现步骤及复现次数。
